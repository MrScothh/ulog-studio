# Getting help

- **How does a page work, what does a number mean?** Read the [documentation](https://github.com/MrScothh/ulog-studio/wiki) (also in [`docs/`](docs/Home.md)), in particular [Logging setup](docs/Logging-setup.md), [Gyro filters](docs/Gyro-filters.md), [Rate loop](docs/Rate-loop.md) and the [FAQ](docs/FAQ.md).
- **Questions, tuning results, ideas:** [Discussions](https://github.com/MrScothh/ulog-studio/discussions).
- **Something is broken or an analysis looks wrong:** [open an issue](https://github.com/MrScothh/ulog-studio/issues/new/choose).
- **Security problem:** see [SECURITY.md](SECURITY.md); please report it privately.

Before attaching a flight log anywhere public, remember it can contain GPS positions, dates and vehicle identifiers.

For PX4 itself (firmware, parameters, flight behaviour) the [PX4 user guide](https://docs.px4.io/) and the [PX4 discussion forum](https://discuss.px4.io/) are the right places.
